# Eom Jin Cho — Production Archive

A professional archive of Eom Jin Cho’s music production, release preparation, studio collaboration and live-event support.

Created for labels, publishers, distributors, production companies and A&R teams, the archive presents selected projects, production workflows, review criteria and supporting evidence from independent music work released under the artist name Omjine.

## Archive structure

- Selected Work — released recordings and project responsibilities
- Production — arrangement, session management, vocal editing and quality control
- Review Criteria — creative direction, version feedback and release preparation
- Sessions & Events — studio collaboration and live-event support
- Evidence — linked coverage, radio selection, playlist inclusion and scholarship documentation
- Contact — professional enquiries and supporting music links

## Evidence and credits

Recordings, session images, project descriptions and external links provide context for the work. Media coverage and playlist inclusion document external recognition; they do not establish production responsibilities or commercial performance.

Project descriptions should distinguish Eom Jin Cho’s contributions from collaborators’ contributions. Omjine identifies the artist project through which much of this work was developed.

## Site files

- `index.html` — page structure and archive copy
- `styles.css` — existing visual system and responsive layout
- `assets/` — project artwork, photographs, session screenshots and supporting images

The site uses relative asset paths and can retain the same structure on GitHub Pages or a custom domain.
